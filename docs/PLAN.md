# 改善計画: 「聞きごたえのある進行」と UI 磨き込み

## ゴール

- コードだけで聞きごたえがある進行（クリシェ、イキスギコード＝ブラックアダー・コード、セカンダリードミナント等）
- 音そのものの気持ちよさ（ベース、ボイスリーディング、ミックス）
- UI は現在の構成を保ちつつ、設定パネルと情報の見せ方を改善。情報量はむしろ増やす

## 現状の課題

1. ベースが無く、構成音を G3〜F#4 に折り畳むだけ。前のコードとのつながりを考えていない
2. 代理コードが文脈を見ない（V/V が出ても V に解決しない）
3. 装飾がコードごとに独立して付いたり外れたりする。sus4 も解決しない
4. 1拍ごとの逐次抽選なので先読みできず、終止（締め）もない
5. 度数＋装飾というデータ表現のため、クリシェや aug、dim7、借用和音、分数 aug が表現できない
6. オシレーターを直接出力しているだけで、音が硬く、音割れしやすい

## 方針

### コードモデル
キーからの相対ルート（半音）＋構成音程（ivs）＋ベースで表す。度数は骨格用のメタ情報として持つ。

- 構成音程は 12 未満を和音構成音、12 以上をテンション（9th=14、♭9=13、#11=18、13=21 …）とする
- コード名とローマ数字は構成音程から生成する（J-POP 流の `IIm7` `♭VIM7` 表記）

### ボイシング
- ベースはルート（分数コードなら指定音）を低音域に置き、前のベースに近いオクターブを選ぶ
- 上声 3〜4 音は、全オクターブ配置の候補から「前の上声からの移動量＋音域の偏り＋密集度」が最小のものを選ぶ

### 生成（8小節先読み）
1. 骨格: 4小節フレーズテンプレートを2つで1セクション（同じものを繰り返すこともある）。小節頭の度数は従来の `calcWeights`（マルコフ＋パターン＋理論補正）から抽選する
2. 色: セクションごとにトライアド / 7th / 9th の「色」を決めて統一感を出す
3. 仕掛け（スパイス量に比例して確率で発動。ノンダイアトニックのものは「代理コード」ON 時のみ）

| 仕掛け | 例（C メジャー） |
|---|---|
| セカンダリードミナント | … → A7 → Dm |
| ツーファイブ挿入 | … → Em7 A7 → Dm |
| 裏コード | G7 → D♭7 → C |
| 経過 dim | C → C#dim7 → Dm |
| イキスギコード（ブラックアダー） | … → Faug/G → C |
| 上行 / マイナークリシェ | C Caug C6 C7 / Am AmM7 Am7 Am6 |
| ベース下降クリシェ | C C/B C/B♭ F/A |
| sus4 解決 | Gsus4 → G7 |
| サブドミナントマイナー | F → Fm → C |
| ♭VI-♭VII-I | A♭ B♭ → C |
| ベース順次（転回） | C → G/B → Am |

4. 終止: セクション末で次の頭がトニックなら、高い確率でドミナント系を置いて締める

### 音
- マスターにコンプレッサーを入れ、軽いリバーブを掛ける
- 上声は2本のオシレーターをわずかにデチューンし、ローパスで角を取る
- ベースは別の音色で鳴らす

### UI（構成は維持）
- 設定を「曲 / 生成 / 演奏 / 音」にグループ分けし、説明文を付ける
- 小節・拍カウンター、セクション内の位置、機能（T/SD/D）、これから鳴るコードと仕掛けのラベル、ボイシング表示を追加する
- 確率メーターは「次の小節の骨格がどの確率から選ばれたか」を表示する
- テンプレートの残骸（index.css）、ライトモードのメーター色、title / lang / favicon を修正する
